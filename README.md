
# 🎮 RBLXBuddy

**RBLXBuddy** is an official **Google Chrome Extension** created by [UsedTempy](https://github.com/UsedTempy). It enhances your Roblox experience by providing seamless analytics, insights, and functionality for Roblox-related activities.

---

## ✨ Features

- 📊 **Advanced Analytics:** Gain valuable insights into Roblox charts and activities.
- 🌟 **User-Friendly Interface:** Intuitive design for easy navigation.
- 🔄 **Dynamic Content Support:** Works on dynamic pages like Roblox charts.
- ⚙️ **Performance-Optimized:** Lightweight and efficient for smooth usage.

---

## 🚀 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/UsedTempy/RBLXBuddy.git
   ```
2. Load the extension in Chrome:
   - Go to `chrome://extensions/`
   - Enable **Developer Mode**
   - Click **Load unpacked** and select the project folder.

3. Start using RBLXBuddy!

---

## 🛠️ How to Use

1. Navigate to Roblox chart pages (e.g., `https://www.roblox.com/charts#/sortName/x`).
2. Use the analytics provided to explore and optimize your Roblox activities.
3. Enable additional features through the extension's options menu.

---

## 📂 Project Structure

- **`manifest.json`**: Defines extension metadata.
- **`background.js`**: Manages background scripts and extension logic.
- **`styles.css`**: Contains custom styles for the UI.
- **`content.js`**: Handles interactions with Roblox webpages.
